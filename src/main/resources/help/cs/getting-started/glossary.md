# Slovník pojmů

| Pojem | Význam |
|---|---|
| **Cyklus skenu** | Jeden úplný průchod Čtení vstupů -> Vykonání programu -> Zápis výstupů. |
| **Vlákno (`T:`)** | Cyklická úloha FreeRTOS (Thread 1 = 1 s, Thread 2 = 100 ms, Thread 3 = 20 ms, Thread 4 = 5 ms). |
| **Pořadí (`O:`)** | Deterministické pořadí vyhodnocení bloků v rámci jednoho vlákna. |
| **Tělo bloku (Courtyard)** | Střední šedá část FBD bloku mezi sloupci vstupních a výstupních pinů. |
| **Konstanta `(=x)`** | Konstanta doby překladu na nezapojeném vstupu. Dvojklikem na pin ji lze upravit. |
| **Sběrnice (Bus)** | Svazek více signálů mezi dvěma bloky vykreslený pod úhlem 45 stupňů (styl KiCad). |
| **Skrytý vodič** | Spoj nahrazený párem značek sítě (OCON/ICON) pro přehlednost na delší vzdálenost. |
| **Příčka (Rung)** | Jeden vodorovný řádek logiky v žebříčkovém schématu (LD) od levé napájecí lišty k cívce. |
| **Makro stránka** | Znovupoužitelná podstránka se vstupy a výstupy, kterou lze vložit jako blok do jiné stránky. |
