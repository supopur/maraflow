# Keyboard Shortcuts

| Shortcut | Action |
|---|---|
| `F1` | Open context-sensitive Help for selected block, tree item, or ST keyword |
| `F7` | Compile project to STM32F407 bytecode |
| `Ctrl+F` / `Cmd+F` | Find in active editor |
| `Ctrl+Z` / `Cmd+Z` | Undo (up to 50 steps) |
| `Ctrl+Y` / `Cmd+Shift+Z` | Redo |
| `Delete` / `Backspace` | Delete selected block(s), wire(s), or graphic element(s) |
